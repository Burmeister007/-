# Страница процесса «От участка до ключей»

Одностраничник по пяти этапам стройки, собранный из картинки
`d0d8d2e4-4e0a-43b1-b3c8-8631ad6672c6.png` в корне репозитория: полоса
режется на пять кадров, они становятся иллюстрациями этапов, а сама полоса —
фоном героя.

## Файлы

| Файл | Что это |
| --- | --- |
| `process.template.html` | разметка и стили, ассеты подставляются как `{{ASSET:имя}}` |
| `process.html` | собранная страница, все ассеты вшиты в data URI |
| `assets/` | кадры в webp и урезанные шрифты в woff2 |
| `prepare_assets.py` | режет исходную картинку и урезает шрифты |
| `build.py` | подставляет ассеты в шаблон и пишет `process.html` |

Правьте `process.template.html`, а не `process.html` — собранный файл
перезаписывается.

## Сборка

```bash
python3 site/build.py                 # достаточно, если ассеты уже в site/assets
python3 site/prepare_assets.py        # если поменялась исходная картинка или шрифты
```

Для `prepare_assets.py` нужны `pillow`, `fonttools` и `brotli`; для `build.py` —
только стандартная библиотека.

## Почему всё вшито в один файл

Страница рассчитана на публикацию как артефакт Claude: там действует строгий
CSP, внешние шрифты, картинки и стили заблокированы. Поэтому шрифты урезаны
до латиницы с кириллицей и вместе с кадрами лежат в самом HTML. Итог — около
0,65 МБ при лимите 16 МБ.

## Что заменить перед публикацией

Сроки, допуски (влажность бруса, отклонение геометрии) и гарантийные
формулировки в тексте — примеры для наглядности. Подставьте значения из своих
регламентов и уберите примечание-черновик в подвале. Обе кнопки в блоке
«Следующий шаг» ведут на `#` — их нужно связать с формой заявки.

## Шрифты

Системные, лицензии свободные: DejaVu Sans Bold (заголовки), Liberation Sans
(текст), DejaVu Sans Mono (номера этапов, сроки, подписи).
