# Одностраничник «Контур»

Лендинг компании, которая строит дома из домокомплекта, и отдельная страница
по этапам стройки. Иллюстрации взяты из картинки
`d0d8d2e4-4e0a-43b1-b3c8-8631ad6672c6.png` в корне репозитория: полоса режется
на пять кадров, они становятся картинками этапов, а полоса целиком — фоном
героя.

## Страницы

| Файл | Что это |
| --- | --- |
| `index.html` | одностраничник: герой, комплектации, этапы, конструктив, вопросы, заявка |
| `process.html` | только этапы — если нужна короткая страница под рассылку или КП |

Каждая страница собирается в двух видах:

| Куда | Файлы | Чем отличается |
| --- | --- | --- |
| Артефакт Claude | `index.html`, `process.html` | фрагмент без `<!doctype>` и `<head>` — их подставляет сам артефакт |
| Обычный хостинг | `dist/index.html`, `dist/process.html` | полный документ: `charset`, `viewport`, `lang="ru"`, описание, иконка, Open Graph |

Для хостинга берите файлы из `dist/`: без `<meta charset>` браузер может
прочитать кириллицу не в UTF-8. Все файлы самодостаточные — шрифты и картинки
вшиты внутрь, внешних запросов нет, работают и с `file://`.

Домен для соцсетей в `dist/` не прописан: в `<head>` лежат закомментированные
`og:url` и `og:image` — раскомментируйте и подставьте свой адрес.

## Печать и PDF

Страницы рассчитаны на «печать в PDF» — их отправляют как КП. На бумаге лист
белый, навигация, кнопки и форма скрыты, вопросы раскрыты, этап и комплектация
не рвутся между листами: одностраничник выходит на 9 листах A4, страница
этапов — на 4. Правила лежат в `partials/print.css`.

## Как устроена сборка

Правьте шаблоны и партиалы, а не `*.html` — собранные файлы перезаписываются.

| Файл | Что это |
| --- | --- |
| `index.template.html` | разметка лендинга |
| `process.template.html` | разметка страницы этапов |
| `partials/base.css` | токены, типографика, герой, график, блок этапов |
| `partials/landing.css` | навигация, комплектации, таблица, вопросы, форма, подвал |
| `partials/print.css` | печать и «сохранить в PDF» |
| `partials/schedule.html` | полоса графика по этапам |
| `partials/stages.html` | пять этапов — общий блок для обеих страниц |
| `partials/reveal.js` | появление блоков при прокрутке |
| `pack.py` | архив `kontur-site.zip` для передачи заказчику |
| `assets/` | кадры в webp и урезанные шрифты в woff2 |

В шаблонах работают две подстановки: `{{INCLUDE:partials/base.css}}` вставляет
файл как есть, `{{ASSET:hero.webp}}` — файл из `assets/` как data URI. Описание
страницы для `<meta name="description">` берётся из блока `<!-- meta -->` в
начале шаблона.

```bash
python3 site/build.py                 # собрать обе страницы
python3 site/build.py index           # только index.html
python3 site/prepare_assets.py        # если поменялась исходная картинка или шрифты
python3 site/pack.py                  # архив для передачи (после build.py)
```

Для `prepare_assets.py` нужны `pillow`, `fonttools` и `brotli`; для `build.py` —
только стандартная библиотека.

## Почему всё вшито в один файл

Страницы рассчитаны на публикацию как артефакт Claude: там действует строгий
CSP, внешние шрифты, картинки и стили заблокированы. Поэтому шрифты урезаны до
латиницы с кириллицей (по 7–9 КБ вместо 300–700 КБ), а кадры лежат в самом
HTML. Итог — около 0,67 МБ при лимите 16 МБ. Файлы в `dist/` собираются из тех
же шаблонов и отличаются только головой документа.

## Архив для передачи

`python3 site/pack.py` кладёт в корень репозитория `kontur-site.zip`: готовые
страницы в корне архива, исходники сборки в `source/`. Папка `source` устроена
так же, как `site/`, поэтому внутри распакованного архива работает
`python3 source/build.py` и собирает те же файлы байт в байт. Сам архив в git
не хранится — он пересобирается скриптом.

## Что заменить перед публикацией

- **Название и контакты.** «Контур» — рабочее имя, телефон, почта и адрес цеха
  в подвале — заглушки.
- **Цены и сроки.** Цифры в комплектациях, полоса графика и сроки этапов —
  примеры для наглядности.
- **Показатели конструктива.** Сечения, толщины утепления, значения R,
  влажность бруса, марка бетона — проставьте свои из проекта.
- **Гарантийные условия** в блоке вопросов.
- **Форма заявки** пока не отправляется: по нажатию она честно пишет об этом в
  интерфейсе. Подключите обработчик и удалите этот блок в `<script>`
  `index.template.html`.
- **Примечание-черновик** в подвале — убрать, когда данные станут настоящими.

## Оформление

Палитра снята с самой картинки: тёмно-синий ночной площадки `#04101f`,
стальной синий, чертёжный белый, оранжевый касок `#f0a02c`. Светлая и тёмная
темы описаны токенами в `partials/base.css`; герой остаётся тёмным в обеих,
потому что лежит на иллюстрации.

Шрифты системные, лицензии свободные: DejaVu Sans Bold в заголовках,
Liberation Sans в тексте, DejaVu Sans Mono на номерах этапов, сроках и
подписях.
